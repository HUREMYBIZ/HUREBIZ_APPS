# HURE Hollow Block Counter

A simple mobile-friendly hollow block stack calculator.

## Automatic Stack
Enter the bottom layer and number of layers. Each succeeding layer decreases by 1.
Formula: total = layers × (bottom + top) / 2.

## Irregular Stack
Enter every layer from bottom to top separated by commas.

## History
Saved locally in the browser. No database is required for this version.

## Deploy
This is a static web app. Upload index.html to GitHub Pages, Render Static Site, Railway-compatible static hosting, Netlify, or similar hosting.
